# Практична 08 — повний комплект

Файли:
- sluzhba.py — служба журналу замірів (код із повідомлення користувача)
- nenadiyna_merezha.py — проксі ненадійної мережі (код із повідомлення користувача)
- kliyent.py — клієнт із прапорцями таймауту, повторів та ключа
- zvit.md — шаблон звіту для заповнення фактичними вимірюваннями

Усі файли мають лежати в одній теці.

Термінал 1: python sluzhba.py
Термінал 2: python nenadiyna_merezha.py
Термінал 3: python kliyent.py --kilkist 10

Для кожного сценарію з README практичної використовуй відповідну команду.
Перед новим сценарієм перезапускай службу, щоб лічильник починався з нуля.
