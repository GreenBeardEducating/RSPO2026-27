# Практична 06 — NumPy та Numba

## 1. Характеристики середовища

- **Процесор:** AMD64 Family 25 Model 80 Stepping 0, AuthenticAMD
- **Логічних процесорів:** 16
- **Потоків Numba:** 16
- **Python:** 3.13.9
- **NumPy:** 2.5.3
- **Numba:** 0.68.0
- **Задача:** обчислення множини Мандельброта
- **Розмір зображення:** 692 × 519 пікселів
- **Максимальна кількість ітерацій:** 1000
- **Кількість точок:** 359 148

## 2. Основні результати

| Реалізація | Час виконання, с | Прискорення | Збіг з еталоном |
|---|---:|---:|---|
| Чистий Python | 10.019418 | ×1.00 | Еталон |
| Numba `@njit` | 0.215842 | ×46.42 | Так |
| Numba `prange` | 0.036999 | ×270.81 | Так |
| NumPy `endpoint=False` | 14.873023 | ×0.67 | 26 розбіжних точок |

Прискорення обчислено відносно часу чистого Python — 10.019418 с. Для Numba використано найкращий час із трьох вимірювань.

## 3. Час компіляції Numba

| Реалізація | Час першого виклику, с |
|---|---:|
| `@njit` | 0.785875 |
| `prange` | 0.638178 |

Час компіляції вимірювався окремо й не включений у час повторного виконання функцій.

## 4. Окремі прогони

| Реалізація | Прогін 1, с | Прогін 2, с | Прогін 3, с | Найкращий час, с |
|---|---:|---:|---:|---:|
| Чистий Python | 10.019418 | — | — | 10.019418 |
| Numba `@njit` | 0.215842 | 0.220001 | 0.217996 | 0.215842 |
| Numba `prange` | 0.036999 | 0.038151 | 0.067745 | 0.036999 |

Для чистого Python у наведених результатах є лише один прогін. Для обох реалізацій Numba виконано три прогони.

## 5. Перевірка точності NumPy

| Варіант координат | Кількість розбіжних точок |
|---|---:|
| `endpoint=False` | 26 із 359 148 |
| `endpoint=True` | 32 068 із 359 148 |

Numba `@njit` і `prange` пройшли перевірку `np.array_equal` та точно збіглися з еталоном. NumPy має розбіжності, тому його результат потребує додаткової перевірки.
